## 本 agent 尚未确认的关键问题（❓）

1. ❓ **ESP32 的 CANH/CANL 是接到测试板的 D+/D− 上吗？** 若如此，ESP32 与测试板是**并联**在同一对差分线上——那么"监听"和"发送"走的是同一条物理通道，发送时理论上也能被 FM03 收到。
2. ❓ **FM03 能否单独上电？** 已知它能由 RS3 供电（不能单独开机），但用户此前有一次是用**普通电源适配器经同一测试板**给 FM03 单独供电的（那次 RS3 未上电）。**这种单独供电方式是否可重复**未确认。
3. ❓ **发送时是否需要改动接线。** 本 agent 此前在计划里含糊地写了"隔离台架"，但**从未确认过物理上要怎么接才能让 ESP32 发出的帧到达 FM03**。这是 M5 的前置未知项。
4. ❓ **总线上会不会同时出现两个主节点。** 若 RS3 也在上电状态，ESP32 一旦发送即形成双主控争用——这是安全边界明确禁止的情形。

## 对"主动阶段"的真实约束（据此更新计划）

- 之前 S0–S5 的表把"发送"写得很简单，**但没有说明发送时 RS3 必须处于什么状态、接线要不要动**。现更正为：
  - **发送的前提**：RS3 **必须断电**（或至少不参与总线），只剩 FM03 在总线上，避免双主控。
  - **发送的通道**：ESP32 需要与 FM03 处于**同一对差分线**上。若现状（ESP32 并在测试板 D+/D− 上）已经满足，则无需改线；若 ESP32 只并接在别处，则需改线。**这一点必须先由用户确认。**
  - **模式**：ESP32 需要从 Listen Only 切到 NORMAL 才能发送（固件已支持长按 BOOT 切换）。
- **本 agent 不会自行接线、不会自行烧录、不会发送任何帧。** 上述任一项在用户确认前，主动阶段不启动。
